# 🧠 음성 데이터를 활용한 치매 증상 감지 시스템
**맑은 소리** | IITP 프로젝트 (디스부 예비 4조)

---

## 📌 프로젝트 개요

고령화 사회에서 증가하는 치매 환자를 위한 **비침습적·AI 기반 조기 진단 시스템**입니다.  
LLM 챗봇과 TTS를 활용해 고령자와 자연스러운 대화를 유도하고, 수집된 음성 데이터에서 음향·발화 특성을 분석하여 **정상 / 경도인지장애(MCI) / 치매**를 자동으로 분류합니다.

> 2023년 기준 65세 이상 인구 비율은 17.5%, 치매로 인한 연간 사회적 비용은 약 **15조 원**에 달합니다.  
> 본 프로젝트는 병원 방문 없이 집에서 음성만으로 치매를 조기에 발견하는 것을 목표로 합니다.

## 🎯 목표

1. **비침습적 치매 조기 진단** — 음성 데이터만으로 치매 여부 판별
2. **AI 기반 분류 모델 개발** — 음향·발화 특성을 결합한 멀티모달 딥러닝 및 머신러닝 모델 구현
3. **집단 간 언어 특성 변화 규명** — 정상/MCI/치매 그룹의 음성 패턴 차이 정량화

---

## 🔧 수행 내용

### 1. LLM 챗봇 및 TTS 구현
- **KoAlpaca** 모델을 감성 대화 데이터로 파인튜닝하여 고령자 대화 유도용 챗봇 구현
- TTS(Text-to-Speech)로 AI 응답을 음성 출력
- 대화 중 언어 특성 실시간 분석으로 치매 위험 신호 감지

### 2. 음향 특성 모델 (Acoustic Feature Model)
- 음성 데이터 잡음 제거 후 **Mel-Spectrogram** 추출
- CNN + MLP 멀티모달 딥러닝 구조: 음향 특성은 CNN, 성별 정보는 MLP로 처리 후 결합

### 3. 발화 특성 모델 (Speech Feature Model)
- STT(Speech-to-Text)로 음성을 텍스트 변환
- 추출 특성: **발화당 단어 수, 음소착어, 도치, 간투사, 수정, 반복, 후속 발화 개시 시간**
- XGBoost, Random Forest, Elastic Net, SVM 머신러닝 모델 구현

### 4. 이중(단계별) 분류 시스템
```
1차 분류: 정상 / 비정상(치매 의심)
      └─ 비정상일 경우
2차 분류: 경도인지장애(MCI) / 치매(중증)
```

### 5. 결과 시각화 및 UI
- 월별 치매 위험 지수 그래프
- AI 자동 생성 월간 언어 분석 리포트
- 위험군/정상군에 따른 시각적 신호(색상, 아이콘) 구분

## 📊 모델 성능 결과

### 정상 / 비정상 분류

| 모델 | 정확도 | 정밀도 | 재현율 | F1 Score |
|------|--------|--------|--------|----------|
| CNN + MLP (음향) | 0.53 | 0.29 | 0.48 | 0.34 |
| Random Forest (발화) | 0.82 | 0.82 | 0.82 | 0.82 |
| **XGBoost (발화)** | **0.85** | **0.85** | **0.85** | **0.85** |
| Elastic Net (발화) | 0.60 | 0.37 | 0.60 | 0.45 |
| 복합 모델 | 0.60 | 0.30 | 0.50 | 0.37 |

### 경증 / 중증 분류

| 모델 | 정확도 | 정밀도 | 재현율 | F1 Score |
|------|--------|--------|--------|----------|
| CNN + MLP (음향) | 0.49 | 0.26 | 0.43 | 0.31 |
| Random Forest (발화) | 0.75 | 0.76 | 0.76 | 0.76 |
| **XGBoost (발화)** | **0.81** | **0.82** | **0.82** | **0.82** |
| Elastic Net (발화) | 0.52 | 0.28 | 0.52 | 0.36 |
| 복합 모델 | 0.52 | 0.26 | 0.50 | 0.34 |

> **결론:** 발화 특성 기반 XGBoost 모델이 1차·2차 분류 모두에서 최고 성능 달성 (정확도 0.85 / 0.82)
